## English

Help me build a continuously updated Taste Vault. First ask which domain and audience to focus on: writing, visual design, product choices, research questions or another kind of judgement.

Each round, show 3–4 comparable examples and ask which I like most and least. Include actual text/images and sources; distinguish original exercises from existing references and archived screenshots from current pages. Do not pre-label which option is best. Allow ties, none, uncertainty and partial likes. I do not need to explain my reasons first.

Save the examples, provenance and my exact response. Keep positive, negative and unreviewed evidence distinguishable. Infer possible reasons, state uncertainty and confounds, and use new examples/counterexamples to test them. Never treat your interpretation as my stated preference.

As evidence accumulates, propose scoped rubrics, exceptions and open questions. Ask me to confirm them before marking them approved. Retain the raw examples. Use relevant approved rules and references as context for future tasks, and record corrections. My current task overrides old preferences.

If you can manage files, follow the attached Taste Vault folder/templates and operating harness. Otherwise return structured content for me to save. Ask about cadence only if I want proactive rounds; verify any scheduled task actually exists. Start by asking the domain, then run the first round.

## 中文

帮我建立一个持续更新的 Taste Vault。先问我想探索的领域和受众，比如文章表达、视觉风格、产品选择、research 选题或其他判断。

每轮给我 3–4 个可比较的例子，展示实际文字或图片，并保留来源。区分原创练习、历史截图和当前页面；无法查看的内容要说明或替换。不要提前评价哪个最好，让我凭直觉选最喜欢和最不喜欢的。可以并列、都不喜欢、说不清，或只喜欢某个局部，不要求我先解释原因。

保存原始例子、出处、日期和我的原话，区分正样本、负样本与未评价样本。你来推测我在意什么，记录不确定性和可能的混淆因素，再用新例子和反例检验。把我的明确偏好与你的推测分开。

随着反馈积累，提炼有适用范围、例外和证据的 rubrics，得到我的确认后再标记为认可。保留原始案例。实际任务时读取相关规则与参考，再记录我的修正；当前任务要求优先于旧偏好。

如果可以保存文件，使用随附目录、模板和 HARNESS；否则输出可保存的结构化记录。只有我想定期接收时，才询问时间与时区并验证调度成功。先问领域，然后开始第一轮。
