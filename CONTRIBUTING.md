# Contributing

Keep examples original or shareable, with provenance. Explain whether changes affect selection, inference, storage, application or evaluation. Avoid unsupported claims that this workflow improves objective decision quality.

Run `python3 -m unittest discover -s tests -v` and validate the completed example. Keep prompts/model providers decoupled. Never include private vaults, secrets, customer data or downloaded images without redistribution rights. Update both quickstarts for user-visible workflow changes.
